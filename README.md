Food Ordering System – Java Console Application

The Food Ordering System is a Java‑based console application that replicates the basic workflow of an online restaurant ordering platform. It is designed as a beginner‑friendly project to practice object‑oriented programming concepts, data handling, and user interaction through a command‑line interface. The application allows customers to browse a menu of food items, place orders, and generate a final bill with discounts applied, making it a practical example of how e‑commerce and restaurant systems operate behind the scenes.
Each food item in the system is represented with attributes such as item ID, name, category, price, and available quantity. Customers can view the menu, search for specific items, and add them to their order cart. The cart supports operations like adding new items, removing unwanted ones, and updating quantities. This ensures flexibility and mirrors the real‑world process of modifying an order before checkout.
The system also calculates the total bill dynamically based on the items selected. To make the application more realistic, a discount mechanism is included: depending on the total purchase amount, customers receive tiered discounts (for example, 5%, 10%, or 15%). This feature demonstrates conditional logic and enhances the user experience by simulating promotional offers commonly found in food delivery apps.
Once the order is finalized, the program generates a detailed bill that lists all items, quantities, individual prices, applied discounts, and the final payable amount. Additionally, the system includes functionality to save order information, which can later be extended to file storage or database integration for persistent records.

Key Features

Display menu with all food items
Search items by name or ID
Add, remove, and update items in the cart
View current order details
Calculate total bill with discounts
Generate and save final bill

Tech Stack

Language: Java
Environment: Console (VS Code / Command Prompt)
Data Handling: In‑memory lists (extendable to database)
